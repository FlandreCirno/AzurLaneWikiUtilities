处理完最后一份公文后，我终于放下笔，轻轻呼出一口气，下意识按了按有些发紧的眉心。<br>
正准备稍作休息时，一道安静的视线却落在了我身上。普利茅斯不知何时已站在桌前，安静地注视着我。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>

<span style="color:#4eb24e;">普利茅斯：</span><br>
贵安，指挥官大人。<br>
恕我冒昧……您最近，似乎总是微微蹙着眉。是工作上遇到了什么不顺利的事吗？<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
都这么明显了么？<br>

<span style="color:#4eb24e;">普利茅斯：</span><br>

<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
谢谢你，普利茅斯。不过真的不用太担心。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
不行哦~既然已经被我发现了，就不能这样放着不管。<br>

<br>
普利茅斯轻轻垂下眼帘，像是在认真思考什么。<br>
片刻后，她重新抬起头，那双温柔的眸子里多了几分笃定。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
指挥官大人，请问您明天有紧急的安排吗？<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>

<span style="color:#4eb24e;">普利茅斯：</span><br>
那么，就请把明天交给我吧~<br>
我想为您准备一份……特别的休整计划。<br>
从早晨开始，到夜晚结束，普利茅斯会负责让您放松下来。<br>
如果顺利的话，到了明天结束的时候……您的表情一定会比现在舒展许多。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
听起来还真是相当正式的安排啊。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
因为这是很重要的事，我会把那些让您不够高兴的部分全部排除掉的。<br>
嗯……这也是只属于指挥官大人的，特别辅佐。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
这样会不会太麻烦你了？<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
不会。能为指挥官大人准备这样的计划，普利茅斯反而会觉得高兴。<br>
而且……我也想亲眼看看。当您真正放松下来时，会露出怎样的表情。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
……好吧，那明天就拜托你了。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
是，请交给我吧~普利茅斯会认真准备，尽我所能地让您度过绝对高兴的一天。<br>
所以今天，就请您好好期待明天的安排吧，呵呵~<br>
<br>
普利茅斯朝我微微提起裙摆，行了一礼。那张一贯安静温柔的脸上，此刻正浮现着难得一见的、毫不掩饰的期待。<br>
随后，她便带着那份令人无法拒绝的认真与从容，离开了指挥室。<br>
