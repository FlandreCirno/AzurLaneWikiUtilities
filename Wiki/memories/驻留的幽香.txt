港区·重樱庭院<br>
难得有片刻闲暇，我受{{AF|白凤}}之约，与她并肩漫步在庭院深处。<br>
微风穿过回廊，带来一阵若有若无的清雅香气，让人不自觉地放松下来。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
这庭院里的香气很特别……闻着就让人平静。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
呵呵……指挥官大人喜欢就好。<br>
今日的庭院与这缕幽香，都是{{AF|白凤}}特意为您准备的哦~<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
听起来，你好像对我的喜好很了解？<br>

当然呢……因为只有{{AF|白凤}}懂得此地的风雅，也知道什么样的景致，最适合您。<br>
至于别处那只大呼小叫，总喜欢往指挥官身边凑的“宠物”……<br>
呵呵，自然是不懂这些的。<br>
<br>
{{AF|白凤}}的语气中带着一丝不易察觉的自得，但很快被她脸上温雅从容的笑意掩去。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
落英逐流水，浮世芳华本如梦，幽香伴长眠。<br>
指挥官大人觉得这句与眼前的景色，是否相称？<br>

<br>
{{AF|白凤}}轻轻挽住我的手臂，领我继续向前漫步。<br>
一片枯黄的落叶打着旋飘落，最终落入庭院的流水之中，顺流而下。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
落叶随水而去，春樱也总有凋谢的一天。<br>
虽然这香气让人沉醉，但一想到美好的东西总是稍纵即逝，还是会觉得有些可惜。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
可惜么？呵呵……<br>
那么，指挥官大人觉得，在这短暂如朝露的浮生之中，万物于何时最为动人呢？<br>
是含苞待放的娇嫩，郁郁葱葱的繁盛，还是这般随风零落的凄绝？<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
万物的每个时刻，都有其美丽之处。不过比起我自己，我更想听听{{AF|白凤}}的想法。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
若要说“物哀”……对{{AF|白凤}}而言，当一切喧嚣沉入寂静、生机被彻底收束的那一瞬，反而最美。<br>
那种美，安静得令人移不开视线。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
也许吧。不过，比起任其消散，如果能把那一瞬的美好长久留住就更好了。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
将片刻留住么……指挥官大人果然很温柔。<br>
既然您如此不舍，那{{AF|白凤}}自然也有办法，将它们留存下来。<br>
<br>
{{AF|白凤}}微微倾身靠近，唇边挂着一抹幽然而神秘的微笑。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
指挥官大人，请再把时间借给{{AF|白凤}}一会儿吧。<br>
接下来，{{AF|白凤}}将以各种香木，为您复刻这缕转瞬即逝的幽香。<br>

<br>
二 私密之约<br>
港区·{{AF|白凤}}居所<br>
跟随着{{AF|白凤}}走进房间，屋内显然精心布置过。<br>
温和的光线照射在屏风上，映出摇曳的竹影，空气中安静得只剩下呼吸声。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
焚香扫榻，涤净尘嚣。这是{{AF|白凤}}只为指挥官大人一人准备的礼遇哦~<br>
看着您这样毫无防备地踏进只属于{{AF|白凤}}的地方……呵呵，实在很难不让人心生欢喜呢~<br>
<br>
{{AF|白凤}}身姿优雅地站在火钵前，抬手示意我来到她身边。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
既然要留住那份风雅，自然该依照古法一步步来。<br>
在正式制香之前，还需先完成闻香之礼。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
要我做什么？<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
嗯，首先——需要褪去您沾染了外界气息的外套。<br>
<br>
{{AF|白凤}}的吐息拂过耳畔，用手轻柔地抵住我的双肩，脱下外套。<br>
她身上那股若隐若现的幽香，也随之更清晰地萦绕在周围。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
那么，接下来便是{{AF|白凤}}的闻香之礼。<br>
第一礼，为“静坐”。<br>
请挺直脊背，放空心绪，将外面的纷扰暂且留在门外吧。<br>
<br>
我依言端正坐好，{{AF|白凤}}却趁机绕到我的身后。微凉的手轻轻落在我的肩上，顺着脊背缓慢抚过。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
慢慢地~慢慢地~对，就是这样。<br>
把那些无关紧要的事都忘掉……从现在起，您的心只需留给{{AF|白凤}}就好。<br>
<br>
在她轻柔的引导下，我原本紧绷的肩颈渐渐放松了下来。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
很好，那么第二礼，为“净手”。<br>
<br>
{{AF|白凤}}端来一只盛着温水与花瓣的木盆，轻放在桌上。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
唯有洗去尘世杂气，才能触碰最纯粹的风雅。<br>
来，指挥官大人，请把手交给我吧。<br>
<br>
她托起我的手，缓缓浸入温热的水中，动作细致而从容。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
指尖上还留着文件与海风的味道呢~<br>
就让{{AF|白凤}}替您一点一点洗净……最终只留下与我有关的气息。<br>
<br>
温水包裹着皮肤，让{{AF|白凤}}微凉的指尖显得格外清晰。<br>
待她用丝帕仔细拭去我手上的水痕后，房间里的温度似乎都跟着上升了些。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
最后一礼，为“屏息”。<br>
制香之时，最忌心神浮动。<br>
指挥官，请闭上眼睛，感受我的呼吸，与我保持同样的节奏。<br>
<br>
闭上眼睛，她温热的吐息轻轻落在近旁，带着异样的幽香，令我的感官不自觉地集中了起来。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
没错……吸气……呼气……<br>
跟着我的引导就好，不要去想别的。<br>
在同样的呼吸里，让自己的嗅觉变得敏锐。<br>
那么现在，我们可以开始真正地制香了。<br>

<br>
三 试香<br>
待我重新睁开眼时，{{AF|白凤}}已完成了诸多准备。<br>
桌案上整齐摆放着数种香材，香炉中的香灰也被细细理成圆润的丘形，顶端银叶上卧着一片名贵香木。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
接下来，{{AF|白凤}}要为指挥官大人调一味庭院幽香。<br>
不过在此之前，还请您先品鉴一下作为底调的主香是否合意。<br>
<br>
{{AF|白凤}}将香炉托到我的手中，随后靠近我的身侧，以极自然的姿态引导起我的动作。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
指挥官大人的动作有些生疏呢~<br>
请用右手像这样……半掩在香炉上，只留下一道细细的空隙。<br>
对，就是这样。<br>
然后，缓缓吸气……去感受它最真实的气息。<br>
<br>
香烟自指缝间细细溢出。<br>
与此同时，{{AF|白凤}}近在咫尺的体香与呼吸也一并落入感官，使那缕香气多了几分难以言明的暧昧。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
感觉如何，指挥官大人？<br>
这被双手小心拢在掌中的香气，就像那些稍纵即逝的美——<br>
若不将它妥善珍藏，它便会从指间悄然溜走。<br>
所以，想要留住珍视之物，就该像这样，稳稳地握住才行。呵呵……<br>
<br>
她的声音轻缓，几乎带着蛊惑般的意味，让人有些恍神。<br>
就在这时——啪嗒一声。<br>
{{AF|白凤}}宽大的衣袖轻轻扫过一旁的案几，几只盛着香粉的瓷碟一并倾倒。<br>
细碎的香粉散落在她的衣襟与领口之上。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
没事吧？有没有伤到哪里？<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
无妨，只是一点小意外而已。<br>
不过，{{AF|白凤}}现在的姿势不太方便……<br>
指挥官大人，能否帮我清理一下这些香粉呢？<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
我来？可我对这些香材并不熟，万一弄混了——<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
嗯……说得也是。<br>
不过这些香粉既已沾上{{AF|白凤}}的体温，指挥官，不如您就在{{AF|白凤}}身上试香？<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
……在你身上试香？<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
来吧，指挥官大人。请替{{AF|白凤}}找出方才庭院中的那一缕幽香。<br>
只有找到最契合的主香，我们的专属香方才能完成。<br>
<br>
{{AF|白凤}}微微整理衣襟，露出沾染香粉的锁骨与领口，温柔的语气中带着不容回避的期待。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
……好，我试试看。<br>
<br>
我俯身靠近，循着香粉散落的位置仔细辨认。<br>
雪松的清冷、花木的甜腻……各类沉香的气息彼此交织，却都不是庭院中那缕略带寂静的幽香。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
这边的味道偏冷，应该不是。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
那就再试试别处，不用着急，{{AF|白凤}}会一直陪着您。<br>
<br>
她抬手拨开发丝，露出颈侧与肩头。<br>
我顺着香气层层分辨，终于在那纷杂香调之下，嗅到了一丝极淡却格外鲜明的气息。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
……是这个。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
呵呵……指挥官大人的嗅觉，比{{AF|白凤}}想象中还要敏锐。<br>
既然主香已经找到了，接下来，我们便可以开始合香了。<br>

四 彼此的气味<br>
试香结束后，{{AF|白凤}}将桌案重新收拾妥当，神情也恢复了先前那副优雅从容的模样。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
方才指挥官大人说，想把那一刻的美好留住。<br>
可若只依靠香材本身，是不够的。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
那还缺什么？<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
那庭院里的景致，是{{AF|白凤}}与指挥官大人共同经历的。<br>
既然要把那段时光封存下来，这味香的灵魂，自然不能只由我一人赋予。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
所以，要我也一起参与？<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
正是如此，在香道中，这一步被称作合香。<br>
需要我们两人掌心与心意，共同温养香泥，才能让香意真正凝聚。<br>
<br>
{{AF|白凤}}来到我身侧，紧挨着跪坐下来，将调制好的香粉倒入玉钵，轻轻推到我面前。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
接下来，就让我们一起把这缕幽香和成香丸吧。<br>
<br>
我依言将手探入玉钵，托起一团湿润细腻的香泥。<br>
下一秒，{{AF|白凤}}的双手也从两侧覆了上来，稳稳包住我的手背。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
香丸的揉制讲究力道的均匀与心意的相通。<br>
指挥官大人，请与{{AF|白凤}}保持同样的节奏。<br>
香木与药材需经过反复研磨、调和与塑形，才能显出最深处的香韵。<br>
<br>
在她的引导下，我们一同揉捏、挤压、团搓着香泥。<br>
温热的香泥在掌心慢慢成形，而她的指尖则时不时擦过我的手心，留下轻微却难以忽视的触感。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
若是指挥官也能像这团香泥一样，让我慢慢了解、细细辨认……<br>
直到真正触碰到您的本质，那一定会是件非常令人着迷的事吧。<br>
<br>
{{AF|白凤}}轻柔地呢喃着，带着一种近乎执拗的专注。<br>
掌中的香泥在反复温养下逐渐圆润，也仿佛真的融入了彼此的气息。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
您感受到了吗，指挥官大人？<br>
它正在一点点吸收我们的温度与记忆。<br>
从今往后，这颗香丸会记得今日的一切。<br>
它会替{{AF|白凤}}，替您，把这一刻好好保存下来。<br>

五 三景之香<br>
不多时，一枚色泽深润，整体圆润光滑的香丸静静躺在锦帕上。<br>
{{AF|白凤}}垂眸望着它，露出了一抹满足的浅笑。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
终于完成了，这颗香丸里，已经融进了我们的心意与温度。<br>
既然指挥官大人方才如此配合，{{AF|白凤}}自然也该奉上最好的回礼。<br>
接下来，请静心安坐，让{{AF|白凤}}为您点燃它吧。<br>
<br>
{{AF|白凤}}小心夹起香丸，放入早已备好的香炉中，片刻后，一缕香气在房间中晕开。<br>
那气味与庭院中的幽香极为相似，却比先前柔和些，也多了一丝近乎缠绵的余韵。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
真厉害……竟然真的像把方才的庭院带到了这里。<br>
<span style="color:#4eb24e;">{{AF|白凤}}：</span><br>
只是“像”，还远远不够哦~<br>
为了让过程更有趣一些，指挥官陪{{AF|白凤}}玩一个闻香的小游戏如何？<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
什么游戏？<br>
