1 無法忽視的異常<br>
港區·指揮室<br>
午後的陽光透過落地窗，靜靜鋪灑在堆滿文件的辦公桌上。<br>
處理完最後一份公文後，我終於放下筆，輕輕呼出一口氣，下意識按了按有些發緊的眉心。<br>
正準備稍作休息時，一道安靜的視線卻落在了我身上。普利茅斯不知何時已站在桌前，安靜地看著我。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
……<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
普利茅斯？怎麼了？<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
貴安，指揮官大人。<br>
恕我冒昧……您最近，似乎總是微微蹙著眉。是工作上遇到了什麼不順利的事嗎？<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
都這麼明顯了嗎？<br>
倒也不是遇到了什麼麻煩……只是最近要處理的事稍微多了一點。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
原來如此……<br>
所以，才會露出這樣的表情嗎……<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
其實沒什麼大不了的，休息一下應該就好了。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
可是……我還是有些在意。指揮官大人是為了讓大家都能愉快地生活，才這樣勞累的。<br>
所以我也希望……您也能一直高興。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
謝謝你，普利茅斯。不過真的不用太擔心。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
不行哦~既然已經被我發現了，就不能這樣放著不管。<br>
如果連指揮官大人的心情變化都沒能好好照顧到的話……那我身為輔佐者，未免也太不稱職了些。<br>
<br>
普利茅斯輕輕垂下眼簾，像是在認真思考什麼。<br>
片刻後，她重新抬起頭，那雙溫柔的眼眸裡多了幾分篤定。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
指揮官大人，請問您明天有緊急的安排嗎？<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
明天麼，倒是沒有什麼特別的行程，怎麼了？<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
那麼，就請把明天交給我吧~<br>
我想為您準備一份……特別的休息計劃。<br>
從早晨開始，到夜晚結束，普利茅斯會負責讓您放鬆下來。<br>
如果順利的話，到了明天結束的時候……您的表情一定會比現在舒展許多。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
聽起來還真是相當正式的安排。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
因為這是很重要的事，我會把那些讓您不夠高興的部分全部排除掉的。<br>
嗯……這也是只屬於指揮官大人的，特別輔佐。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
這樣會不會太麻煩妳了？<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
不會。能為指揮官大人準備這樣的計劃，普利茅斯反而會覺得高興。<br>
而且……我也想親眼看看。當您真正放鬆下來時，會露出怎樣的表情。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
……好吧，那明天就拜託妳了。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
是，請交給我吧~普利茅斯會認真準備，盡我所能地讓您度過絕對高興的一天。<br>
所以今天，就請您好好期待明天的安排吧，呵呵~<br>
<br>
普利茅斯朝我微微提起裙擺，行了一禮。那張一貫安靜溫柔的臉上，此刻正浮現著難得一見的、毫不掩飾的期待。<br>
隨後，她帶著那份令人無法拒絕的認真與從容，離開了指揮室。<br>

第二天一早，我照約定來到了普利茅斯的房間。<br>
當房門打開時，空氣中已經飄來淡淡的香氣，桌上也整齊擺好了茶具與幾碟精緻的小點心。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
貴安，指揮官大人。<br>
歡迎來到今天休息計劃的第一站。<br>
第一項內容，是與指揮官大人共進早餐，希望您能開心。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
一大早就開始準備……辛苦妳了。<br>

不辛苦，還有一盤蔬菜沙拉需要製作……在那之前，您可以先嚐嚐這些小點心。<br>

'''''<span style="color:black;">选择项2：妳也別太辛苦了</span>'''''<br>

<br>
普利茅斯朝我輕輕一笑，隨即轉身走向了一旁的廚房。<br>
我正準備伸手去拿桌上的點心，廚房那邊卻突然傳來一陣令人不安的高頻嗡鳴。<br>
「滋滋滋滋——」<br>

普利茅斯？發生什麼事了？<br>

咳、咳咳——指揮官大人——<br>
我……我正在切菜……請您……退後……<br>
<br>
我快步走進廚房，只見普利茅斯正微微俯身，專注地看著料理台。<br>
而她手中握著的，並不是普通菜刀，而是一台專業的雷射切割設備。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
普利茅斯……妳這是在做什麼？<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
啊，指揮官大人，請暫時不要靠近。切割時產生的細小碎屑，或許會濺到您身上。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
只是切菜……真的有必要用到這種設備嗎？<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
有必要哦~雷射切割不會壓迫食材產生形變，能夠把食材切出更理想的斷面，口感也會接近完美。<br>
指揮官大人，請看——<br>
<br>
普利茅斯用餐叉輕輕叉起一片胡蘿蔔，遞到了我面前。<br>
那片胡蘿蔔在晨光下泛著光，表面平滑得幾乎不像蔬菜本身。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
這一片的切面是不是很漂亮呢？<br>
我想，它在舌尖上滑過的時候，應該會有接近絲綢般的口感。<br>
請您試試看。<br>
<br>
她微微前傾，將那片胡蘿蔔送到我嘴邊。<br>
看著她那副認真等待評價的模樣，我還是張口吃了下去。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
唔……<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
怎麼樣？<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
口感……確實很特別。表面平滑得有點超出想像，咬下去也十分脆爽。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
真是太好了……看來，和我的預想大致一致呢。<br>
指揮官大人，品嚐過這道菜品，有沒有讓您覺得高興一點？<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
當然，光是這份心意，就已經讓我很開心了。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
太好了……<br>
<br>
聞言，普利茅斯輕輕眨了眨眼，隨後露出一絲安靜而滿足的笑意。<br>
只是下一刻，她的目光又緩緩移向了我的眉間。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
……還是不夠嗎。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
嗯？什麼？<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
……不，沒什麼。<br>
今天的安排還有很多——我會繼續努力，直到您露出真正舒展的表情為止。<br>

3 遊樂園的神槍手<br>
港區·遊樂園<br>
用過早餐後，普利茅斯依照事先擬定好的計劃，帶著我來到了港區的遊樂園。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
指揮官大人，這裡就是今天第二項安排的地點。<br>
根據資料顯示，遊樂園是人類在短時間內轉換心情、提升愉快感的高效場所之一。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
其實，光是和妳這樣出來走走，我的心情就已經好了不少。<br>
<br>
聽到我的話後，普利茅斯抬眸看向我，像是認真確認什麼。<br>
只是片刻之後，她還是輕輕搖了搖頭。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
不行哦，指揮官大人。<br>
請不要在這種時候安慰我。<br>
現在的您……眉間還沒有完全放鬆下來。所以，普利茅斯還要繼續努力才行。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
妳還真是一點都不肯鬆懈。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
呵呵~因為今天的我，是專屬於您的輔佐者。<br>
那麼，您想先從哪裡開始呢？<br>
無論是悠閒一些的項目，還是稍微刺激一點的內容……我都已經做好準備了。<br>
<br>
普利茅斯的話語有些猶豫，我順著她的目光看向不遠處，剛好一輛雲霄飛車正沿著軌道攀升至頂端。<br>
下一秒，伴隨著俯衝而下的車身，尖叫聲頓時響徹了半個園區。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
雲霄飛車嗎……這種項目還是之後再說吧。<br>
我們先隨便逛逛。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
明白了。那麼，就先以較為平穩的方式進行心情調整吧。<br>
<br>
我們沿著園區的小路慢慢往前走。不久後，一處無人的射擊遊戲攤位吸引了我的注意。<br>
木板上整齊排著一排彩色氣球，而獎品台中央則擺著一隻幾乎有半人高的玩偶熊。<br>
旁邊的牌子寫著：二十發全中，即可獲得特等獎。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
這個看起來倒是挺有意思。普利茅斯，要不要試試？<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
射擊嗎？明白了……<br>
既然是指揮官大人有興趣的項目，那當然可以。<br>
<br>
她走到攤位前，伸手拿起了提供的玩具槍。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
果然，槍身平衡性一般，準星也有偏移，如果想穩定地全部命中，恐怕還差了一些。<br>
不過幸好，我事先準備了詳細的全中方案。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
什麼方案？<br>

下一刻，普利茅斯從隨身攜帶的包包中，取出了各種輔助用具，瞄具、穩定架、測距輔助模組一應俱全。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
普利茅斯，這些東西應該是不被允許的吧？<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>

二十發彈丸無一落空，原本色彩鮮明的一整排目標，轉眼間便被掃蕩得乾乾淨淨。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>

<span style="color:#4eb24e;">普利茅斯：</span><br>

普利茅斯走到了領獎區，片刻後，抱著那隻幾乎快和她一樣高的巨大玩偶熊，重新站到了我面前。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
指揮官大人，請您確認本輪計畫的成果。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
謝謝……沒想到真能拿到特等獎。<br>

希望這份禮物能讓您感到高興。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
嗯，我很開心。<br>
<br>
聽到我準確的回答後，普利茅斯輕輕眨了眨眼，唇邊也浮現出一抹淺淺的笑意。<br>
只是很快，她的目光又緩緩落向了我的眉間。<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
……還是不夠嗎。<br>
<span style="color:#3498DB;" class="shikikanname">指挥官</span>：<br>
什麼？<br>
<span style="color:#4eb24e;">普利茅斯：</span><br>
難道是因為，這隻玩偶熊的尺寸還不足以令您充分滿意？<br>

不不，已經很夠了。<br>
我現在的心情真的很好，所以你先冷靜一點。<br>

是這樣嗎……那好吧。<br>
既然遊樂園專案對您確實有效，那麼接下來就繼續按照原定計劃推進。<br>
我會繼續努力的，呵呵~<br>

說完，普利茅斯抱著那隻巨大的玩偶熊，溫和地站在我身邊。<br>

從視野、風向、人群密度等方面綜合考慮，這裡應當能獲得最好的觀賞體驗。<br>
